# Тематика завдання

**Оптимізація продуктивності серверного рендерингу (SSR) веб-застосунку на основі Next.js з Node.js бекендом**

Завдання видав керівник практики від університету доц. Стримець Сергій Петрович, 07.09.2026

---

## Перелік питань, які підлягають виконанню

### 1. Аналіз вимог до продуктивності SSR та проєктування архітектури Node.js бекенду
- Визначити цільові метрики продуктивності (TTFB, LCP, FCP, TTI) та критерії "до/після" оптимізації
- Спроєктувати архітектуру бекенду: API-шар, шар кешування, шар роботи з базою даних
- Стек: Express, PostgreSQL, Redis для кешування
- Описати схему взаємодії Next.js (SSR) ↔ Node.js API ↔ БД ↔ Redis

### 2. Розробка та оптимізація серверної частини на Node.js
- Реалізувати API-шар на Express (REST-ендпоінти для даних, які рендеряться на сервері)
- Підключити базу даних, оптимізувати запити (індекси, пагінація, select тільки потрібних полів)
- Впровадити кешування Redis (кешування відповідей API, інвалідація кешу, TTL)
- Порівняти продуктивність без кешу / з кешем

### 3. Реалізація та налаштування SSR на Next.js
- Реалізувати сторінки з різними стратегіями рендерингу: SSR (`getServerSideProps`), ISR (Incremental Static Regeneration), Streaming SSR (React Server Components / `renderToPipeableStream`)
- Інтегрувати Next.js-бекенд із Node.js API (fetch/axios, обробка помилок, таймаути)
- Налаштувати кешування сторінок (Next.js cache, CDN/edge кешування, `revalidate`)

### 4. Тестування продуктивності
- Навантажувальне тестування (k6 / Apache JMeter / Artillery) — оцінка пропускної здатності та часу відгуку під навантаженням
- Профілювання (Node.js `--prof`, Chrome DevTools, Next.js built-in profiler) — пошук вузьких місць
- Вимірювання метрик TTFB, LCP (Lighthouse, Web Vitals) до і після оптимізації
- Документування результатів: таблиці/графіки порівняння метрик, висновки

---

## Обраний стек технологій
- **Frontend/SSR:** Next.js (App Router), React
- **Backend:** Node.js + Express
- **База даних:** PostgreSQL
- **Кешування:** Redis
- **Тестування навантаження:** k6
- **Профілювання/метрики:** Chrome DevTools, Lighthouse, Web Vitals

## Орієнтовна структура проєкту
```
practic/
├── backend/          # Node.js API (Express) + Redis + БД
├── frontend/         # Next.js застосунок (SSR/ISR/streaming)
├── load-tests/       # Сценарії k6/Artillery
├── docs/             # Результати вимірювань, звіти, графіки
└── ЗАВДАННЯ.md
```
